# DentVision Architecture

DentVision is an AI Operating System for dentistry: CRM + Shop/Marketplace + Academy + Jobs + Community + Analytics + Finance + Diagnostics, unified by an AI employee runtime.

## Runtime contract

`User → Workspace → Role + Permissions → Data + Memory → Domain Event → AI Reasoning → Permission → Action → Verification → Audit → Memory`

## Non-negotiable boundaries

- Workspace/tenant context is explicit for every data-bearing operation.
- Database and event state are authoritative; LLM context is not durable state.
- AI actions have explicit risk/permission levels: READ, SUGGEST, CONFIRM, EXECUTE, BLOCKED.
- Executable actions must be auditable and idempotent where side effects matter.
- Web and Android share product contracts rather than maintaining incompatible business rules.

## Project control plane

The machine-readable project index lives in `.dentvision/` and is regenerated by:

`npm run project:index`

The index is intended to be the first orientation layer for humans and coding agents before they inspect implementation details.
