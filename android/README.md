# DentVision для Android — кабинет клиники

Нативный клиент кабинета клиники (CRM) к тому же бэкенду, что и веб. Отдельный
модуль: код в `src/` и `dentvision-backend/` он не трогает и в сборку веба не
входит.

## Откуда берутся данные

Ниоткуда, кроме настоящего API. Ни одного выдуманного эндпоинта, поля или
экрана: каждый метод в `data/api/` соответствует существующему маршруту
бэкенда, каждая модель в `data/model/` списана с ответа этого маршрута и с
`src/types.ts`.

Права тоже не переизобретаются. `POST /api/auth/login` возвращает `pages`,
`permissions` и `capabilities` — приложение их сохраняет и показывает ровно то,
что разрешил сервер. Матрицы ролей на устройстве нет.

## Адрес API

`BuildConfig.API_BASE_URL`, задаётся в `app/build.gradle.kts` — те же два
значения, что и в `src/utils/api.ts`:

| Сборка  | Адрес                                 |
|---------|---------------------------------------|
| debug   | `http://10.0.2.2:3001`                |
| release | `https://dentvision-api.onrender.com` |

`10.0.2.2` — это `localhost` машины-хоста с точки зрения эмулятора Android.
Открытый (не-TLS) трафик разрешён только в debug-сборке.

## Сборка

Нужен Android SDK (platform 35, build-tools 35.0.0) и JDK 17+.

```
export ANDROID_HOME=/путь/к/android-sdk
cd android
./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/app-debug.apk`.

## Что готово

- Каркас: Gradle, тема из токенов веба, транспорт, сессия, навигация, оболочка.
- Вход и выход, обновление токена на 401 с одним повтором.
- Экран «Кабинет»: клиника, роль, доступные разделы.
- **Расписание** — день, записи по времени, запись с проверкой занятости.
- **Пациенты** — список, поиск, заведение карты с проверкой ИИН.
- **Медкарта** — аллергии, анамнез, экстренный контакт, страховка.
- **Визиты** — история приёмов пациента и запись нового.

Разделы CRM подключаются этапами. Пункт появляется в меню только вместе с
работающим экраном на настоящих данных: пустых экранов-заглушек в приложении
нет — см. `IMPLEMENTED_PAGES` в `navigation/Destinations.kt`.

## Тесты

```
./gradlew testDebugUnitTest
```

Проверяется то, где ошибка была бы тихой: валидатор ИИН (сверен с настоящим
`src/lib/iin.ts`) и разбор прав (звёздочка суперадмина, лестница действий,
устаревшие имена ключей).

## Чего приложение не делает

Приложение не запускалось ни на эмуляторе, ни на устройстве — в этой среде их
нет. Проверена сборка и юнит-тесты, но не поведение в руках.
